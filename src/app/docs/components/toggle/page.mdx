# Toggle

The latching key — a button with `aria-pressed` whose bevel inverts and
tints while it stays down. It is a lone `ToggleGroupItem`: same
contract as everything here — `pressed` + `onPressedChange` for
controlled use, `defaultPressed` for uncontrolled, click/Space/Enter.

## Demo

<ToggleStates />

```tsx
import { Toggle } from "@/components/ui";

export function ToggleStates() {
  return (
    <div className="flex flex-wrap items-center gap-3">
      <Toggle>Bold</Toggle>
      <Toggle defaultPressed>Italic</Toggle>
      <Toggle disabled>Underline</Toggle>
    </div>
  );
}
```

## Examples

### Controlled state

<ControlledToggle />

```tsx
"use client";

import { useState } from "react";

import { Toggle } from "@/components/ui";

export function ControlledToggle() {
  const [on, setOn] = useState(false);
  return (
    <div className="flex items-center gap-3">
      <Toggle pressed={on} onPressedChange={setOn}>
        Caps lock
      </Toggle>
      <span className="font-mono text-sm">pressed = {String(on)}</span>
    </div>
  );
}
```

## API reference

### Toggle

A real `button` — every button prop is kept.

| Prop             | Type                        | Default | Description |
| ---------------- | --------------------------- | ------- | ----------- |
| pressed          | boolean                     | —       | Controlled on-state. |
| defaultPressed   | boolean                     | false   | Initial on-state when uncontrolled. |
| onPressedChange  | (pressed: boolean) => void  | —       | Fires with the next on-state — controlled and uncontrolled. |
