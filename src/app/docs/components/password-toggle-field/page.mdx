# PasswordToggleField

The password field with the reveal key — a joined well: the input runs
left, a raised key sits flush at its right end and toggles the mask
instantly (`password` ⇄ `text`). Label, hint/error and required markers
wire through the normal `Field` machinery.

All other input props (`value`, `onChange`, `name`, `placeholder`, …)
pass straight through. `type` is retired — the component manages it.

## Demo

<PasswordBasics />

Press the key or Tab to it and Space — the mask flips with no
animation, exactly like the era's "show password" checkboxes.

```tsx
import { PasswordToggleField } from "@/components/ui";

export function PasswordBasics() {
  return (
    <PasswordToggleField
      label="Secret phrase"
      hint="Keep it off the network."
      defaultValue="hunter2"
      className="max-w-xs"
    />
  );
}
```

## API reference

### PasswordToggleField

`Omit<input props, "type">` plus the Field surface. The row is
`w-full`; compose sizes and overrides with the usual `className`
contract.

| Prop     | Type    | Default | Description |
| -------- | ------- | ------- | ----------- |
| label    | string  | —       | Visible label text via the joined `Field`. |
| hint     | string  | —       | Helper text below the well. |
| error    | string  | —       | Assertive error message; wires `aria-invalid` + `describedby`. |
| required | boolean | false   | Label marker + `aria-required`. |

Everything else — `value`, `onChange`, `name`, `placeholder`,
`disabled`, … — is the native `<input>`'s, untouched.
