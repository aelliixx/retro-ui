# Table

The details pane — semantic native table parts wearing the operating
system's list skin: column headers on a sunken sheet between dark
rules, hairline column dividers, rows separated by soft hairlines that
highlight the era way (an accent-tint hover, instant).

Composable and flat: `<Table>` is the `<table>` itself; wrap it in a
`ScrollArea` when columns outrun the pane. No wrappers are invented
for structure you already own — `thead`/`tbody` are semantic and
simply styled. For row headers in the first column pass
`scope="row"` to `TableHead` (and consider `text-start`).

## Demo

<FilesTable />

```tsx
import {
  ScrollArea,
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui";

const FILE_ROWS = [
  { name: "document.txt", size: "12 KB", modified: "yesterday" },
  { name: "budget.csv", size: "4 KB", modified: "last week" },
  { name: "wallpaper.png", size: "82 KB", modified: "a while ago" },
  { name: "autoexec.bat", size: "1 KB", modified: "years ago" },
];

export function FilesTable() {
  return (
    <ScrollArea className="max-w-sm">
      <Table>
        <TableHeader>
          <TableRow>
            <TableHead>Name</TableHead>
            <TableHead className="text-end">Size</TableHead>
            <TableHead className="text-end">Modified</TableHead>
          </TableRow>
        </TableHeader>
        <TableBody>
          {FILE_ROWS.map((row) => (
            <TableRow key={row.name}>
              <TableCell>{row.name}</TableCell>
              <TableCell className="text-end">{row.size}</TableCell>
              <TableCell className="text-end">{row.modified}</TableCell>
            </TableRow>
          ))}
        </TableBody>
        <TableFooter>
          <TableRow>
            <TableCell colSpan={2}>4 objects</TableCell>
            <TableCell className="text-end">99 KB</TableCell>
          </TableRow>
        </TableFooter>
        <TableCaption>Everything you need is already on disk.</TableCaption>
      </Table>
    </ScrollArea>
  );
}
```

## Examples

### Row headers + selected row

`scope="row"` promotes the first column to headers, and rows carry a
`data-state` slot — `selected` tints the row solid.

<RowHeadTable />

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui";

export function RowHeadTable() {
  return (
    <Table className="max-w-sm">
      <TableHeader>
        <TableRow>
          <TableHead className="w-24">Setting</TableHead>
          <TableHead>Value</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow data-state="selected">
          <TableHead scope="row">Protocol</TableHead>
          <TableCell>TCP/IP via modem</TableCell>
        </TableRow>
        <TableRow>
          <TableHead scope="row">Speed</TableHead>
          <TableCell>33.6 kbit/s</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

## API reference

### Table

The `<table>` itself. No props of its own — set widths, spacing and
density through `className`.

### TableHeader / TableBody / TableFooter

Semantic `thead` / `tbody` / `tfoot`, simply styled. No props of their
own.

### TableRow

A `tr` with the era's hover and a `data-state` slot.

| Attribute  | Values            | Notes |
| ---------- | ----------------- | ----- |
| data-state | `"selected"` / —  | Tints the row solid; compose the attribute yourself when selection is interactive. |

### TableHead

A `th` between hairline rules.

| Prop  | Type                                   | Default | Description |
| ----- | -------------------------------------- | ------- | ----------- |
| scope | `"col" \| "row" \| "colgroup" \| "rowgroup"` | "col"  | Native header scope — pass `"row"` for a row-header column. |

### TableCell / TableCaption

`td` and `caption` — no props of their own.
