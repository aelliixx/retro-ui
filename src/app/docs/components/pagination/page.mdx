# Pagination

Page navigation, era style: a rail of numbered keys with `◂`/`▸`
stepping and `…` eliding the pages that don't fit. Edge pages always
show; the window around the current key shrinks to dots as space
demands.

The rail keeps the same width on every page — it holds a fixed number
of slots, so paging never nudges the surrounding layout. Near the
first and last pages the window grows to fill the space the missing
edge slot leaves behind.

It is composition: `<Pagination>` owns the page state and renders a
`<nav>`; lay the rail out with `PaginationPrev`, `PaginationPager`
and `PaginationNext` inside it — move the arrows around or drop
pieces freely.

Keyboard comes free — real buttons, so `Tab`/`Enter`/`Space` behave
as keys. The current key carries `aria-current="page"`.

## Demo

<PaginationRail />

```tsx
import {
  Pagination,
  PaginationNext,
  PaginationPager,
  PaginationPrev,
} from "@/components/ui";

export function PaginationRail() {
  return (
    <Pagination defaultPage={4} totalPages={12}>
      <PaginationPrev />
      <PaginationPager />
      <PaginationNext />
    </Pagination>
  );
}
```

## Examples

### Controlled

Own the page yourself and mirror it in surrounding prose.

<PaginationControlled />

```tsx
import { useState } from "react";

import {
  Pagination,
  PaginationNext,
  PaginationPager,
  PaginationPrev,
} from "@/components/ui";

export function PaginationControlled() {
  const [page, setPage] = useState(2);

  return (
    <div className="flex flex-col items-start gap-2">
      <Pagination
        page={page}
        onPageChange={setPage}
        totalPages={7}
        className="items-center gap-2"
      >
        <PaginationPrev />
        <PaginationPager />
        <PaginationNext />
      </Pagination>
      <span className="font-mono text-[11px] text-ink-muted">
        reading order: page {page} of 7
      </span>
    </div>
  );
}
```

(`onPageChange` receives the next page — swap in your router here if
the rail drives navigation.)

### Compact keys

`size="sm"` shrinks every key; `siblings` narrows the visible window.

<PaginationSmall />

```tsx
import {
  Pagination,
  PaginationNext,
  PaginationPager,
  PaginationPrev,
} from "@/components/ui";

export function PaginationSmall() {
  return (
    <Pagination size="sm" totalPages={5} siblings={0}>
      <PaginationPrev />
      <PaginationPager />
      <PaginationNext />
    </Pagination>
  );
}
```

## API reference

### Pagination

A `<nav>`; every native prop is kept.

| Prop          | Type                 | Default        | Description |
| ------------- | -------------------- | -------------- | ----------- |
| totalPages    | number               | —              | Required. Total page count the nav steps through. |
| page          | number               | —              | Controlled current page. |
| defaultPage   | number               | `1`            | Uncontrolled initial page. |
| onPageChange  | (page: number)       | —              | Fired with the newly selected page. |
| siblings      | number               | `1`            | Pages kept visible on each side of the current one. |
| size          | `"sm" \| "md"`        | `"md"`         | Key scale for every trigger in the nav. |
| label         | string               | `"Pagination"` | Accessible name of the `nav`; name it when several navs share a page. |

The root lays out as a flex row with a unit gap — compose spacing via
`className` through tailwind-merge.

### PaginationPrev / PaginationNext

The stepping keys. Rendered as real `button`s carrying their own
`aria-label`; disabled at the first and last page.

| Prop     | Type                     | Default | Description |
| -------- | ------------------------ | ------- | ----------- |
| disabled | — *(derived)*            | —       | Handled internally; the key is disabled on page 1 / the last page respectively. Your `onClick` still runs first. |

### PaginationPager

The numbered keys, `<ul>`-laid out automatically from the current
page. No props — the rail reads `totalPages`, `page` and `siblings`
from the root.

### PaginationTrigger

A single numbered key, exported for custom rails. Set `active`
yourself (read `page` from your own state).

| Prop   | Type                     | Default | Description |
| ------ | ------------------------ | ------- | ----------- |
| active | boolean                  | false   | Reads as pressed (accent fill, sunken shadow). |
| size   | `"sm" \| "md"`            | root's  | Key scale; inherits the root's. |

### PaginationEllipsis

The `…` non-interactive spacer, exported for custom rails.
