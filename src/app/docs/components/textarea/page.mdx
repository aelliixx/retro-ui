# Textarea

A sunken multi-line well — a native `<textarea>` wearing the
workstation skin: sunken bevel, etched focus, danger border under
`aria-invalid`. `resize-y` is the only motion: pull the bottom edge,
no drawers, no twitches.

## Demo

<NoteTextarea />

```tsx
import { Field, Textarea } from "@/components/ui";

export function NoteTextarea() {
  return (
    <Field
      label="Autoexec notes"
      hint="Resize at the bottom edge; wraps at the column."
      className="max-w-sm"
    >
      <Textarea rows={4} defaultValue={"REM load high, run late\nREM keep off the network"} />
    </Field>
  );
}
```
