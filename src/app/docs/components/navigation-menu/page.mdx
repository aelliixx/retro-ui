# NavigationMenu

The site navigation bar: inline links plus items that pop a content
panel — the "mega menu" primitive. Panels hang flush under (or beside)
the bar, aligned to their trigger and clamped to the window, so the
pointer stays inside the chrome while moving from trigger to panel.

Triggers open on mouse-over or click; panels close on outside click,
focus leaving the bar, or Escape — which returns focus to the trigger.
Open state is a `value`-based slot (`value` / `defaultValue` /
`onValueChange` with `""` = closed), so React state is the single
source of truth.

## API reference

### NavigationMenu

The bar — a `nav` element wrapping the slots.

| Prop          | Type                                                 | Default          | Description |
| ------------- | ---------------------------------------------------- | ---------------- | ----------- |
| label         | string                                               | —                | Accessible name for the bar (`aria-label`). |
| orientation   | `"horizontal" \| "vertical"`                          | `"horizontal"`   | Bar direction; vertical hangs panels to the right. |
| value         | string                                               | —                | Controlled open panel value — `""` closes all. |
| defaultValue  | string                                               | `""`             | Initially open panel value. |
| onValueChange | (value: string) => void                              | —                | Fires with the next value. |

### NavigationMenuList

The row of items. No props of its own.

### NavigationMenuItem

Groups a trigger and its panel; `value` names the slot for controlled
use (defaults to an auto-generated id).

### NavigationMenuTrigger

The popping trigger — hover opens, click toggles, ArrowDown moves
focus into the panel. `chevron={false}` hides the little triangle
for trigger-less-looking items.

### NavigationMenuContent

The hanging panel. Style on `data-state` (`open`/`closed`); reserve a
fixed width via `className` if the contents vary.

### NavigationMenuLink

A link in the bar or panel. `active` marks the current page
(`aria-current="page"` plus the selection recipe).
