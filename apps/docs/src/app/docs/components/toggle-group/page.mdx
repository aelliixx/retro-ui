# ToggleGroup

The segmented switch bank — a horizontal row of joined keys in one
bevel, where each key toggles or mutually-excludes (`type="single"` is
the classic radio-strip look). Real buttons throughout: click, Space
and Enter all toggle; the selected key sits sunken with an accent tint
— the press stayed down, no animation.

Stack it with `className="flex-col"` for a vertical bank; the bevel
`items-stretch` makes every key the same width. Tab walks each key
natively (no roving tabindex) — keep group counts humane and name the
group with an `aria-label`.

## Demo

<AlignBank />

```tsx
import { ToggleGroup, ToggleGroupItem } from "@retro-ui/ui";

export function AlignBank() {
  return (
    <ToggleGroup
      type="single"
      defaultValue="left"
      aria-label="Text align"
      className="w-fit"
    >
      <ToggleGroupItem value="left">Left</ToggleGroupItem>
      <ToggleGroupItem value="center">Center</ToggleGroupItem>
      <ToggleGroupItem value="right">Right</ToggleGroupItem>
    </ToggleGroup>
  );
}
```

## Examples

### Multiple — checkbox bank

`type="multiple"` lets keys latch independently.

<PanesBank />

```tsx
import { ToggleGroup, ToggleGroupItem } from "@retro-ui/ui";

export function PanesBank() {
  return (
    <ToggleGroup
      type="multiple"
      defaultValue={["grid", "list"]}
      aria-label="Visible panes"
      className="w-fit"
    >
      <ToggleGroupItem value="grid">Grid</ToggleGroupItem>
      <ToggleGroupItem value="list">List</ToggleGroupItem>
      <ToggleGroupItem value="preview">Preview</ToggleGroupItem>
    </ToggleGroup>
  );
}
```

## API reference

### ToggleGroup

| Prop          | Type                                                                     | Default   | Description |
| ------------- | ------------------------------------------------------------------------ | --------- | ----------- |
| type          | `"single" \| "multiple"`                                                  | `"multiple"` | Single: one value or `""`. Multiple: an array. |
| value         | string \| string[]                                                        | —          | Controlled selection — shape follows `type`. |
| defaultValue  | string \| string[]                                                        | —          | Initial selection when uncontrolled. |
| onValueChange | (value: string \| string[]) => void                                        | —          | Fires with the next selection. |

### ToggleGroupItem

A real `button` in the bank.

| Prop  | Type   | Default | Description |
| ----- | ------ | ------- | ----------- |
| value | string | —       | The value this key contributes to the group state. |
