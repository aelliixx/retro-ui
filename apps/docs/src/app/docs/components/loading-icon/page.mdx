# LoadingIcon

The classic busy-hourglass. It *flips* every 1.2s — instant, like an
animation frame from the era, no easing — and holds still entirely
under `prefers-reduced-motion`. The sand pile (accent fill) makes the
flip legible because the outline alone is centrosymmetric.

## Demo

<LoadingIconSizes />

Three sizes and the standalone default (which announces "Loading…"
politely to screen readers).

```tsx
import { LoadingIcon } from "@retroui/ui";

export function LoadingIconSizes() {
  return (
    <div className="flex items-center gap-3">
      <LoadingIcon className="size-3" label={null} />
      <LoadingIcon label={null} />
      <LoadingIcon className="size-6" label={null} />
      <LoadingIcon />
    </div>
  );
}
```

## API reference

### LoadingIcon

A `span` carrying `role="status"`.

| Prop      | Type             | Default       | Description |
| --------- | ---------------- | ------------- | ----------- |
| className | string           | `"size-4"`    | Size it here — `size-3`, `size-6`, etc. |
| label     | string \| null   | `"Loading…"`  | Screen-reader announcement. Pass `null` when visible loading text surrounds the icon. |
