# AspectRatio

A frame that holds its shape at any width. The era's thumbnails never
reflowed — they scaled — so this part takes a `ratio`, reserves the
shape, and lets the contents fill it.

Children fill the frame absolutely; give it an `<img>` or `<video>`
and it is stretched to cover, exactly like photo wells in old
explorer windows. The frame ships with the house windowed chrome
(ink border, sunken silver) and composes away through `className`.

The image fills whatever the shape is — `ratio` trades an expression,
not a class hunt.

### Any content, not just media

Anything inside fills the frame absolutely — content is your layout.

<AspectRatioSquare />

```tsx
import { AspectRatio } from "@retroui/ui";

export function AspectRatioSquare() {
  return (
    <AspectRatio className="w-24" ratio={1 / 1}>
      <div className="flex h-full w-full items-center justify-center font-pixel text-sm text-ink-muted">
        1 : 1
      </div>
    </AspectRatio>
  );
}
```

## API reference

### AspectRatio

A `div`; every native prop is kept. The shape is set with the modern
`aspect-ratio` style property, so the frame scales with its width.

| Prop  | Type   | Default | Description |
| ----- | ------ | ------- | ----------- |
| ratio | number | `4/3`   | Width ÷ height the frame keeps, e.g. `16/9`. |
