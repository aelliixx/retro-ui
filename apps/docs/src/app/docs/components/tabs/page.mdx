# Tabs

The file-folder tab control — real `tablist`/`tab`/`tabpanel` ARIA
with a roving tabindex: Arrow keys (plus Home/End) walk the triggers
and moving focus selects (automatic activation, like Radix's default);
click selects the old way. Inactive panels stay mounted but `hidden`,
so form state inside them survives switching.

Trigger and content ids derive deterministically from the tab value,
so `aria-controls` / `aria-labelledby` line up without lifted
registration.

## API reference

### Tabs

The root — a `div` owning the value and the id scheme.

| Prop         | Type                       | Default | Description |
| ------------ | -------------------------- | ------- | ----------- |
| value        | string                     | —       | Controlled selected tab value. |
| defaultValue | string                     | —       | Initially selected tab value when uncontrolled. |
| onValueChange| (value: string) => void    | —       | Fires with the newly selected value. |

### TabsList

The tab strip. No props of its own.

### TabsTrigger / TabsContent

| Prop  | Type   | In     | Description |
| ----- | ------ | ------ | ----------- |
| value | string | Trigger, Content | The tab's value — unique within the group; the panel it answers. |

The selected trigger loses its bottom border and overlaps the panel's
top hairline by 1px — tab and page read as one carved sheet.
