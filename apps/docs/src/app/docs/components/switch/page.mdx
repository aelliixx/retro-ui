# Switch

The power toggle — a sunken track with a square beveled knob that
jumps between the two ends of the rail the instant you click. Built on
`button role="switch"` with `aria-checked`; toggles with click, Space
and Enter for free.

Management mirrors `Checkbox`: controlled (`checked` +
`onCheckedChange`) or uncontrolled (`defaultChecked`).

## API reference

### Switch

A real `button` (`role="switch"`) — every button prop is kept.

| Prop            | Type                        | Default | Description |
| --------------- | --------------------------- | ------- | ----------- |
| checked         | boolean                     | —       | Controlled on-state. |
| defaultChecked  | boolean                     | false   | Initial on-state when uncontrolled. |
| onCheckedChange | (checked: boolean) => void  | —       | Fires with the next value — controlled and uncontrolled. |
| tinted          | boolean                     | true    | Hides the on-state rail tint for surface-only switches. |

### The veto

A consumer event handler calling `event.preventDefault()` suppresses
the flip — same rules as `Checkbox`.
