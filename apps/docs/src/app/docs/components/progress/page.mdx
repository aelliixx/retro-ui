# Progress

The copy meter: a sunken trough with a hard-stop accent fill — a solid
block, no gradient — that runs flush into the end wall. Value and
maximum are ordinary numbers; `aria-valuenow` reports the percentage,
and `data-state="complete"` lands at full.

## Demo

<ProgressStates />

```tsx
import { Progress } from "@retro-ui/ui";

export function ProgressStates() {

}
```

## Examples

### Wired to a Slider

Two windowed parts, one piece of state — the meter reads from the
knob.

<SliderWiredProgress />

```tsx
"use client";

import { useState } from "react";

import { Progress, Slider } from "@retro-ui/ui";

export function SliderWiredProgress() {
  const [value, setValue] = useState(40);
  return (
    <div className="flex w-64 flex-col gap-3">
      <Progress value={value} aria-label="Copy progress" />
      <div className="flex items-center gap-2 text-sm text-ink">
        <Slider
          value={value}
          onValueChange={setValue}
          min={0}
          max={100}
          aria-label="Adjust the meter"
        />
        <span className="font-mono text-xs">{value}%</span>
      </div>
    </div>
  );
}
```

## API reference

### Progress

A `role="progressbar"` trough.

| Prop  | Type   | Default | Description |
| ----- | ------ | ------- | ----------- |
| value | number | 0       | Current value (0–max). |
| max   | number | 100     | The ceiling; the percentage derives from `value / max`. |

The component checks for an accessible name: pass `aria-label` (or let
visible text around it serve). `aria-valuenow` is the rounded
percentage, omitted at 0.
