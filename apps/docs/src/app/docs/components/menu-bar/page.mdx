# MenuBar

The classic pull-down menu strip. Menus open on hover or keyboard
focus — the era's hover-preview — with plain CSS: no state, no portal,
no delay. Each item is a real `button`, so Tab walks into the open
list and Enter fires it.

Deliberately omitted: the `menubar`/`menu` roles, since arrow-key
roving can't be honored without JS. Shortcuts shown on the right are
displays only — bind real keys yourself.

## Demo

<WindowMenus />

Hover across the three titles and the lists swap in place; tab into an
open menu and Enter fires an item.


## API reference

### MenuBar

The strip — a `nav` element.

| Prop  | Type   | Default | Description |
| ----- | ------ | ------- | ----------- |
| label | string | —       | Accessible name for the strip (`aria-label`). |

### Menu

One title and its dropdown — the list hugs the title's left edge by
default.

| Prop  | Type                             | Default   | Description |
| ----- | -------------------------------- | --------- | ----------- |
| label | ReactNode                        | —         | The menu title — hover or focus opens the list below it. |
| align | `"start" \| "end"`               | `"start"` | Which side the dropdown hugs; `"end"` hangs it at the right edge. |

### MenuItem

A real `button` in the list.

| Prop     | Type   | Default | Description |
| -------- | ------ | ------- | ----------- |
| shortcut | string | —       | Right-aligned display-only shortcut, e.g. "Ctrl+S". |

### MenuSeparator

A hairline between groups. No props of its own.
