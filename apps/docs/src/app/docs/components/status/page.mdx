# Status

The presence pip, on its own — the little availability dot roster
lists and chat windows drew next to every name. It carries four
presence values drawn from the library's own tokens, and can stand
alone or carry a visible label.

The pip is purely visual and `aria-hidden`. Pass `label` when the
value needs to be read aloud, or let surrounding text carry the
meaning — as `Avatar` does with its name. (Avatar imports this
component for its corner pip.)

## API reference

### Status

A `span`; every native prop is kept.

| Prop  | Type                                        | Default    | Description |
| ----- | ------------------------------------------- | ---------- | ----------- |
| value | `"online" \| "away" \| "busy" \| "offline"`  | `"online"` | Which presence to report, drawn from shared presence tokens. |
| size  | `"sm" \| "md" \| "lg"`                      | `"md"`     | Pip scale; resize freely via `className`. |
| label | ReactNode                                    | —          | Visible text rendered after the pip. Screen readers read this, never the pip. |
