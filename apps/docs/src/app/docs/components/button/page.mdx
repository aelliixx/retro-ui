# Button

A key that presses — the two-tone bevel inverts the instant it goes
down and pops back on release, hover tints the face, and keyboard focus
draws the era's dotted etched rectangle inside the border. Five variants
and four sizes cover the usual dialog travels.

## API reference

### Button

A real `button` — click, Space and Enter behave natively. `type`
defaults to `"button"` so a stray key never submits a form.

| Prop    | Type                                                                                                    | Default        | Description |
| ------- | ------------------------------------------------------------------------------------------------------- | -------------- | ----------- |
| variant | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive"`                                      | `"secondary"`  | Face and press treatment of the key. |
| size    | `"sm" \| "md" \| "lg" \| "icon"`                                                                        | `"md"`         | Height and padding scale. `icon` is a square key — give it an `aria-label`. |
