# Skeleton

The loading tile — the era's placeholder: a sunken block wearing the
fine checkerboard dither, standing in for content not yet on the disk.
No shimmer; waits here are static.

Two shapes: `<Skeleton />` is a generic tile you size via `className`
(`h-4 w-32` for a text line), and `<Skeleton loading={loading}>…</Skeleton>`
wraps live content — the shell paints *onto* the child element, which
keeps its dimensions and layout while `loading` is true. It mirrors
Radix Themes' API, minus the shimmer.

## Demo

<SkeletonTiles />

```tsx
import { Skeleton } from "@retro-ui/ui";

export function SkeletonTiles() {
  return (
    <div className="flex w-72 gap-3">
      <Skeleton className="size-10 shrink-0" />
      <div className="flex flex-1 flex-col gap-2">
        <Skeleton className="h-4 w-3/4" />
        <Skeleton className="h-4 w-1/2" />
        <Skeleton className="h-4 w-5/6" />
      </div>
    </div>
  );
}
```

## Examples

### Wrapping live content

The shell paints over the switch without adding a wrapper node —
flip `loading` and the real control returns, same box.

<SkeletonContent />

```tsx
"use client";

import { useState } from "react";

import { Button, Skeleton, Switch } from "@retro-ui/ui";

export function SkeletonContent() {
  const [loading, setLoading] = useState(true);
  return (
    <div className="flex flex-col gap-3">
      <div className="flex items-center gap-3">
        <Skeleton loading={loading} className="rounded-none">
          <Switch defaultChecked />
        </Skeleton>
        <span className="text-sm text-ink">AutoSave</span>
      </div>
      <Button size="sm" onClick={() => setLoading(!loading)}>
        {loading ? "Reveal" : "Re-paint the shell"}
      </Button>
    </div>
  );
}
```

## API reference

### Skeleton

A `span` shell; empty shells are promoted to `display: block` so sizes
mean anything.

| Prop    | Type    | Default | Description |
| ------- | ------- | ------- | ----------- |
| loading | boolean | true    | Whether the skeleton shell replaces the children's paint. |

With children, the shell renders onto the child element (no wrapper
node); bare text children are supported, with the same inline-metric
normalization Radix applies.
