# Card

The window recipe as a container: optional hatched titlebar, a
hairline-chrome body, a footer rail, and three depths — `raised` (the
default bevel), `flat` (printed on the page) and `inset` (a sunken
well). Everything here is a plain semantic `div`-family element, so
layout is yours.

## API reference

### Card

| Prop    | Type                                    | Default     | Description |
| ------- | --------------------------------------- | ----------- | ----------- |
| variant | `"raised" \| "flat" \| "inset"`          | `"raised"`  | Depth of the pane. `raised` carries the two-tone bevel, `flat` prints the same box bare, `inset` sinks it into a well. |

### CardHeader

| Prop    | Type                        | Default   | Description |
| ------- | --------------------------- | --------- | ----------- |
| variant | `"plain" \| "titlebar"`     | `"plain"` | `titlebar` paints the hatched strip and restyles `CardTitle` inside it to small, bold, uppercase micro-caps — the classic window caption. |

### CardTitle

An `h3` caption. No props of its own.

### CardDescription

Muted supporting line (`p`). No props of its own.

### CardContent

The padded body. No props of its own — compose freely.

### CardFooter

The status rail along the bottom edge. No props of its own.
