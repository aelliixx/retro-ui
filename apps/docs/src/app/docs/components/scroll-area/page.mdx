# ScrollArea

The pane with the trough scrollbars — a sunken well that scrolls its
overflow. The scrollbars themselves are the native ones, already
skinned by the global stylesheet, so dragging works everywhere and the
component stays zero-JS.

Pass `label` to expose the pane to assistive tech: it becomes a
`role="region"` with `aria-label` and takes `tabIndex={0}` so keyboard
users can scroll it directly.

## API reference

### ScrollArea

A sunken `div` — height and width are yours via `className`; scroll
where the content overflows.

| Prop  | Type   | Default | Description |
| ----- | ------ | ------- | ----------- |
| label | string | —       | Accessible name — promotes the well to a labelled scroll region with keyboard focus. |
