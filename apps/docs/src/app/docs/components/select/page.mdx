# Select

A sunken dropdown well — the native `<select>`, untouched underneath:
keyboard section jumps, form value, and the platform's own list panel.
Options wear the era (accent highlight, checked mark), and where the
browser supports the modern customizable-select engine, the dropdown
panel itself is skinned too; everywhere else the native panel renders.

## API reference

### Select

A native `<select>` — every prop flows through. No props of its own.

The olive "▼" arrow chip on the right end, the sunken well, the danger
border on `aria-invalid` and the dropdown panel styling are part of the
`select-base` recipe baked into the component; compose on top with the
usual `className` contract.
